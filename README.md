# PMM Antigravity — Portfolio Website

Welcome to the **PMM Antigravity** portfolio repository. This project is a digital showcase of my independent research into trajectory-stable Artificial General Intelligence (AGI). It serves as my MIT application portfolio and an interactive visualization of the theories and hardware designs detailed in my AGI thesis.

## About the Project

*Project Antigravity* aims to establish a mathematically rigorous framework for safe, autonomous AI. Standard models today lack hardware-observable guarantees of safety. This portfolio documents a proposed solution: the **APU-X Neuromorphic Substrate**.

The website features interactive visualizations of key concepts, including:
- **Global Integrity Monitor (GIM)**: An eigengap-based trigger that gates autonomous action.
- **Differential Active-Set Masking (DASM)**: A zero-drift snapshot protocol for perfect hardware rollback.
- **Caloric Entropy Masking**: Thermal management within the chip's physical layers (Carbon Nanotube Pillars & Graphene/h-BN shunts).
- **Stiefel & Banach Space Simulations**: Empirical validation of convergence and stability.

## Architecture

This website is built with a focus on performance and a "Neural Brutalism meets Academic Rigor" aesthetic. It utilizes:
- **Vanilla HTML / CSS / JavaScript** for a lightweight, dependency-free foundation.
- **GSAP (GreenSock)** for high-performance scroll and transition animations.
- **Three.js** for interactive 3D visualizations (e.g., the APU-X substrate layers and the Stiefel manifold).
- **D3.js** for rendering complex convergence charts and mathematical plots.
- **KaTeX** for fast, high-quality typesetting of mathematical proofs and equations.

## Running Locally

Because this project is built using native web technologies, no heavy build steps or bundlers are required. 

To view the site locally, you can use any static file server. For example, using Node.js:
```bash
npx serve
```
Then, open the provided localhost link (typically `http://localhost:3000`) in your browser.
